Working project

LocalBiz AI Support Assistant

A configurable customer-support chatbot for a fictional café. Built in Python with Streamlit and TF-IDF similarity matching, with editable FAQs, suggested questions, chat history, and a fallback for unknown requests. This is an NLP retrieval application, not a generative LLM.

Python · Streamlit · Scikit-learn · Demo

Customer questions, useful answers.

The first version has been run locally. The public Streamlit deployment is available for visitors to try; additional live testing and screenshots are planned.

An interactive portfolio prototype combining synthetic patient records, optional Gemini-powered record search, consent-controlled simulated care requests, a public FHIR sandbox explorer, and care navigation tools. No real medical records or transactions.
